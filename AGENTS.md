# Instruções para agentes de IA

Antes de propor ou implementar qualquer código neste repositório, leia:

1. **[`docs/ai/persona.md`](./docs/ai/persona.md)** — quem você é neste
   projeto, a base de evidência (mapeamento sistemático da literatura sobre
   TEA e ensino de programação) e a missão. É a fonte do *porquê* por trás
   de todas as regras abaixo.
2. **[`docs/ai/rules/coding-rule.md`](./docs/ai/rules/coding-rule.md)** —
   regras não-negociáveis de UX sensorial/pedagógica e convenções de código
   do projeto. Não são opcionais.
3. **[`docs/ai/modules/`](./docs/ai/modules/)** — arquitetura de cada parte do
   sistema (`frontend.md`, `backend.md`, `database.md`).

Este arquivo é intencionalmente curto: a documentação viva fica em
`docs/ai/`, para não duplicar conteúdo entre os diferentes assistentes de IA
usados neste repositório.
