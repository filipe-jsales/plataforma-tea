# Ilustrações — origem e licença

Os 8 SVGs neste diretório (`avatar-cat`, `avatar-dog`, `avatar-bird`,
`avatar-fish`, `login-sun`, `login-moon`, `login-star`, `login-tree`) foram
**desenhados originalmente para este MVP** (formas geométricas simples,
sem uso de banco de assets de terceiros) — não há restrição de licença de
terceiro a rastrear.

São placeholders funcionais, não peças de design final: mesmo estilo visual
(emblema circular colorido + ícone branco de traço simples) em todos os 8,
propositalmente consistente. Antes de produção, considerar substituir por
um set profissional com o mesmo `assetRef`/estilo — ex. um pacote de
pictogramas open-source de licença permissiva (como
[OpenMoji](https://openmoji.org), CC BY-SA 4.0) mantendo os mesmos nomes de
arquivo, para não precisar alterar `illustrationAssets.ts` nem o banco.

Nenhum arquivo tem animação embutida (requisito do fluxo de login do
aluno — ver `docs/ai/modules/frontend.md`).
